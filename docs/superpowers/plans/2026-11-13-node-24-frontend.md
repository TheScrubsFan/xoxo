# Node 24 Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Установить и собрать существующий фронтенд под Node 24 и проверить игру.

**Architecture:** Сохранить Vue 2 и Webpacker 4, заменяя лишь зависимости и настройки, несовместимость которых подтверждена. Если это потребует существенной переделки, остановиться и отдельно согласовать замену сборщика.

**Tech Stack:** Node 24, Yarn 1, Rails 6.0, Webpacker 4, Webpack 4, Vue 2, PostgreSQL, Redis.

**Spec:** `docs/superpowers/specs/2026-11-13-node-24-frontend-design.md`

## Global Constraints

- Сохранить Vue 2, интерфейс и контракт Rails API; не обновлять Rails целенаправленно.
- Работать в ветке `1_update_ruby`; не удалять существующие пользовательские файлы.
- Не менять игровой сценарий намеренно; найденные несвязанные дефекты сообщать отдельно.
- Если потребуется существенная переделка сборки, остановиться до перехода к резервному подходу.

## Review Focus

- Чистая установка: `yarn install --frozen-lockfile` успешно выполняется на Node 24.
- Production-сборка: выходные файлы доступны Rails через manifest.
- Стили и Vue-компоненты: страница игры отображается без ошибок компиляции и ошибок консоли.
- Сетевой сценарий: два пользователя получают состояние игры и ход через HTTP и Action Cable.
- Регрессия бэкенда: полный `bundle exec rails test` проходит на Ruby 3.0.1.

### Task 1: Совместимость установки и сборки

**Files:**
- Modify: `package.json`, `yarn.lock`, при необходимости `config/webpack/environment.js` и `config/webpacker.yml`.
- Modify: `README.md` — фактические версии и команды после успешной проверки.

**Interfaces:**
- Consumes: `@rails/webpacker` 4.3.0, входные файлы `app/javascript/packs/main.js` и `application.js`.
- Produces: установка и сборка с Node 24 и Yarn 1; manifest и packs, доступные Rails через существующие `javascript_pack_tag` и `stylesheet_pack_tag`.

- [ ] **Step 1:** Выполнить `node --version` и `yarn install --frozen-lockfile`; зафиксировать ошибку `node-sass` 4.14.1 при текущем Node 24.
- [ ] **Step 2:** Исследовать минимальный способ заменить транзитивный `node-sass` на совместимый Sass без замены Vue и Webpacker. Проверить, какие загрузчики реально используют Sass; выбрать совместимое решение, не фиксируя догадку как установленный факт.
- [ ] **Step 3:** Изменить только необходимые зависимости и конфигурацию; обновить `yarn.lock`. При установке и сборке устранять только подтверждённые проблемы Node 24; если нужна существенная переделка сборщика, остановиться и сообщить пользователю.
- [ ] **Step 4:** Запустить `yarn install --frozen-lockfile` и `node --version`; ожидается успешный код выхода и версия Node 24.
- [ ] **Step 5:** Под Ruby 3.0.1 выполнить `RAILS_ENV=production SECRET_KEY_BASE=<временное-значение> bundle exec rails webpacker:compile`; ожидаются успешная сборка и `public/packs/manifest.json` с `main.js` и `main.css`. Если Rails требует дополнительные переменные окружения, использовать временные значения без записи секретов в репозиторий.
- [ ] **Step 6:** Обновить README точными версиями и командами установки и сборки; выполнить документированные команды и убедиться в успешном результате.
- [ ] **Step 7:** Выполнить `DISABLE_SPRING=1 bundle exec rails test` под Ruby 3.0.1; ожидается не менее 16 тестов и 0 ошибок и падений.
