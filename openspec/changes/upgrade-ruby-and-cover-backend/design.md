# Design

## Context

Приложение использует Ruby 2.7.1, Rails 6.0.3.4, PostgreSQL, Devise, Blueprinter и Action Cable. В тестах присутствуют только закомментированные шаблоны. Запуск на Ruby 2.7.1 остановился при загрузке нативного `pg` из-за пути к `libpq`; наличие библиотек и сервера для Ruby 3.0.1 ещё не проверено.

## Goals / Non-Goals

**Goals:** получить воспроизводимый запуск на Ruby 3.0.1 и защитить контракт, используемый Vue-клиентом, автоматическими проверками.

**Non-Goals:** не обновлять Rails целенаправленно, не заменять Vue и не менять намеренно правила игры; исправления, необходимые для запуска и согласованных сценариев, допустимы и документируются.

## Decisions

1. Сначала обновить Ruby и только необходимые зависимости, затем выполнить ручную дымовую проверку и написать тесты. Альтернатива — восстановить старое окружение и сначала создать базис — надёжнее для сравнения, но задерживает работу; выбран быстрый путь с осознанным риском.
2. Проверить `pg` и его нативную привязку на Ruby 3.0.1, обновить совместимую версию при необходимости и зафиксировать зависимости. Не предполагать, что смена Ruby сама устранит проблему `libpq`.
3. Использовать существующий Rails Minitest и тестовую PostgreSQL-базу. Интеграционные тесты проверяют ответы, изменения базы и трансляции; отдельные тесты логики проверяют победу и ничью. Существующие фикстуры предварительно проверить и исправить при необходимости.
4. Сохранять текущий формат JSON и событий для Vue. Некорректные ходы и возможные нарушения безопасности фиксировать отдельно; не закреплять ошибочное поведение как обязательное и не расширять объём исправлений без согласования.

## Risks / Trade-offs

- [Нет работающего базиса до обновления] → Сопоставлять поведение с кодом и README, документировать обнаруженные отличия и ручную проверку.
- [Ruby 3.0.1 устарел, Rails 6.0 и гемы могут быть несовместимы] → Считать Ruby промежуточным шагом, обновлять только необходимое и фиксировать ограничения.
- [PostgreSQL или нативные библиотеки недоступны] → Диагностировать отдельно, описать воспроизводимую настройку; не считать bundle check проверкой загрузки `pg`.
- [Состояние игры может отличаться от ожидаемого] → Выявленные сбои и дефекты отделять от изменений совместимости, согласовывать расширение объёма.

## Migration Plan

Зафиксировать версии и lock-файл, подготовить отдельную тестовую базу, запустить приложение, выполнить ручную проверку и автоматический набор. Для отката развернуть предыдущую ревизию с Ruby 2.7.1 и прежним lock-файлом; схема данных намеренно не меняется.
