# Proposal

## Why

Перед обновлением Rails и заменой фронтенда необходимо получить запускаемое приложение и тестовую страховку бэкенда. Запуск на Ruby 2.7.1 заблокирован библиотекой PostgreSQL, поэтому сначала переходим на доступный Ruby 3.0.1, принимая отсутствие исходного тестового базиса.

## What Changes

- Перевести проект на Ruby 3.0.1 и обновить зависимости, необходимые для запуска, включая `pg` при необходимости.
- Проверить вручную создание игры, подключение второго игрока и ход; затем покрыть основные HTTP-контракты, рассылку состояния и игровую логику автоматическими тестами.
- Зафиксировать наблюдаемые контракты без намеренного изменения игровых правил; выявленные дефекты разбирать отдельно, если они не блокируют запуск или согласованные проверки.
- Обновление Rails и замена фронтенда в это изменение не входят.

## Capabilities

### New Capabilities

- `game-api`: Основные HTTP-контракты игры и текущего пользователя, состояние игры и оповещения клиентов.

### Modified Capabilities

- Нет существующих спецификаций для изменения.

## Impact

Gemfile и lock-файл, окружение Ruby/PostgreSQL, тестовая инфраструктура и тесты Rails; возможно минимальные исправления совместимости в приложении. Существующие HTTP-ответы и события Action Cable должны сохранять совместимость с текущим Vue-фронтендом.
